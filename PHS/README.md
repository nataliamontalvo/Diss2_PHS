# A&E Attendance Analysis

## Project purpose

This project examines demographic and service-level factors associated
with A&E attendance and develops models for predicting attendance or risk.

## Project structure

- `R/01_import_clean.R`: imports and cleans the data
- `R/02_create_variables.R`: creates derived variables
- `R/03_eda.R`: performs exploratory analysis
- `R/04_comparative_and_risk_analysis.R`: performs group comparisons
- `R/05_predictive_models.R`: fits predictive models
- `R/06_model_evaluation.R`: evaluates model performance
- `report/final_report.Rmd`: produces the final report
